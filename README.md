# WuBu-DLP

A simple Python GUI Wrapper for yt-dlp to download YouTube VODs in maximum quality(COOKIE.TXT). Features a download queue, playlist support, and options to either merge streams or keep high-bitrate video/audio separate for editing.powered by Waefrebeorn Umbrella License v3.0
